# financialcalculatorapp.com

> Fast, private, browser-based financial calculators for loans, mortgages, retirement, and investments.

## 🚀 Features

- **38 Financial Engines**: Mortgages, loan amortization, compound interest, TVM, 401(k), FIRE, ROI, paycheck, and hardware emulators (HP 12C, TI BA II Plus).
- **100% Client-Side Privacy**: All mathematical calculations execute locally in the user's browser via JavaScript. No personal numbers or financial profiles are transmitted or stored on servers.
- **Multilingual Support (i18n)**: 6 languages with complete localization (`en`, `es`, `de`, `ja`, `fr`, `pt`) and SEO-optimized hreflang tags.
- **Multi-Currency System**: Automatic and manual currency conversions across USD, EUR, GBP, JPY, CAD, AUD, CHF, BRL, INR, and MXN with live FX rate scaling or 1:1 nominal mode.
- **Theme Support**: High-contrast, accessibility-tested dark mode and light mode with seamless chart redraws.
- **Monthly Feedback Analytics**: Helpfulness tracking (Yes/No) with dedicated monthly reporting dashboard, CSV export, and email reporting.

## 🧞 Commands

| Command | Action |
| :--- | :--- |
| `npm install` | Installs dependencies |
| `npm run dev` | Starts local development server |
| `npm run build` | Builds production site |
| `npm run check` | Runs Astro and TypeScript typecheck |
| `npm run preview` | Previews production build locally |
